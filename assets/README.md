# Demo 試卷 PDF

示範用練習卷已放置：`demo-worksheet.pdf`（4 頁）

若需更換，檔名必須為：

```
demo-worksheet.pdf
```

勿使用 `demo-worksheet.pdf.pdf` 等雙副檔名，否則 App 無法找到檔案。

完整路徑：

```
assets/demo-worksheet.pdf
```

## 使用方式

1. 用 Word、Canva、Claude 等工具做好 PDF
2. 重新命名為 `demo-worksheet.pdf` 並放到此資料夾
3. 在 TIK 中按 **⬇ PDF** 或 **下載 Demo PDF** 即可下載／預覽

## 說明

- Demo 階段所有學生下載的是**同一份**靜態 PDF（檔名會帶學生姓名，內容相同）
- 尚未放置檔案時，App 會提示你放入 `assets/demo-worksheet.pdf`
- 正式版（V1）將改為後端動態生成個人化試卷
